# YouTubeドパガキ弾幕

YouTubeに投稿されている既存コメントを、動画画面の上に流すChrome拡張です。手入力は不要です。

## Chromeへの読み込み

1. Chromeで `chrome://extensions` を開きます。
2. デベロッパーモードをONにします。
3. 「パッケージ化されていない拡張機能を読み込む」を押します。
4. このREADMEと `manifest.json` が入った内側の「こめっと」フォルダを選びます。
5. 読み込み済みなら、拡張の更新ボタンを押してYouTubeも再読み込みします。

Chromeがこのフォルダを参照するので、読み込み後に移動・削除しないでください。

## 使い方

通常のYouTube動画を開き、動画タイトル横か拡張アイコンの「全件取得（返信込み）」を押します。スクロールせずに、投稿済みの本文と返信を追加取得先の末尾まで取得します。5,000件・60秒の上限はありません。

- タイムコード付きコメントは `1:23` などの指定時刻に同期します。
- タイムコードのないコメントは、取得済みの全体から選んで2.5秒おきに表示します。先頭の数十件だけに偏らないようにしています。
- 取得中も動画と弾幕を見られます。再度押すと一時停止し、「続きから全件取得」で再開します。
- 取得済みコメントと続きの位置を拡張専用IndexedDBに保存します。タブの再読み込み・Chromeの再起動後も復元して再開できます。
- 接続エラー・保存失敗・取得先の循環は未完了として表示します。エラー後も保存済みの続きから再開できます。
- 「最初から再取得」は、この動画の保存コメントを更新し直します。
- タイトル横の名前ボタンでON/OFF、⚙設定で動画の外に設定パネルを開けます。動画内にも右上端の小さな「⚙ 弾幕」だけを置き、同じ設定パネルを開けます。下側のヒートマップは表示しません。時刻付きだけに絞る場合は「時刻のない既存コメントも流す」をOFFにします。

## 件数の見方

「YouTube表示総数」は現在のページの件数、「取得開始時の参考総数」は取得開始時にYouTubeが応答した件数です。「読み込み済み」はこの拡張が取得した、重複のないコメントIDの件数です。返信も含み、進捗に返信件数を表示します。

「取得先の末尾まで取得」は、本文・返信の追加取得先がすべてなくなった状態です。表示総数と一致しない場合は差も表示し、数を合わせるためにコメントを作ったり、重複を追加したりしません。

取得中にコメントが増減することや、YouTubeが応答に含めないコメントがあることにより、表示総数と取得数が一致しない場合があります。すべての追加取得先を処理した結果を、取得件数とともに表示します。

## 演出

ネオン・虹・炎・氷・金・漫画・グリッチ・波・スポットライト・レーザーの10種類をコメントごとに使い分けます。連続するコメントでは同じ種類を避けます。いいね50以上、「神」「天才」「最高」などは大きめに表示します。

停止・シーク・倍速・プレイヤー全画面に追従します。操作ボタンは動画の外にあり、全画面中は全画面を解除して設定します。混雑して文字を安全に置けないコメントは省略します。「まったり」は白い横スクロール、「火花・キラキラ・紙吹雪」は粒子のON/OFFです。OSのモーション抑制がONなら文字を静的に表示します。音や画面全体のフラッシュは追加しません。

NGワード・最低いいね数・目次の除外も設定できます。長いコメントは先頭110文字まで表示します。

## 保存とアクセス

権限は `storage` のみで、コンテンツスクリプトは `www.youtube.com` で動きます。設定はChromeのローカルストレージへ保存し、取得コメントと再開位置は、拡張専用IndexedDBへ保存します。ログイン・APIキー・サーバーは不要です。コメントを外部へ送る処理や、YouTubeへ投稿する処理はありません。

以前の手動追加コメントは表示しません。保存済みのデータは削除しません。

## 対応範囲

通常のYouTube動画と、読み込まれた通常コメントが対象です。Shorts・ライブチャット・埋め込み動画・スマホには対応しません。本文と返信は全件取得の対象です。コメント欄の無効化やYouTubeの画面変更により取得できない場合があります。
